# Project_Portfolio_JMG

Personal portfolio of programming projects for bioinformatics.  A collection of functions, scripts, and workflows aimed at common bioinformatics processes from sequence alignment and quality control to data handling and cleaning to visualizations and analysis. Tools are currently programmed in Bash shell, Python or R languages, each with their own README files and/or documentation.  

- pytools: directory with tools developed with Python
- rTools: directory with tools (functions) developed for R
- workflow_RNAseq: Rmarkdowen and html files for examples of the processing, quality control and analysis of RNA sequencing data in R
  - workflow_RNAseq.rmd: working file for ongoing tool generation and pipeline development for RNAseq analysis in R
  - workflow_RNAseqQC.rmd: example of data downloading, processing, and QC for RNAseq analysis
