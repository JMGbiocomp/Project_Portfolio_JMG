# Project_Portfolio_JMG

Personal portfolio of programming projects for bioinformatics.  A collection of functions, scripts, and workflows aimed at common bioinformatics processes from sequence alignment and quality control to data handling and cleaning to visualizations and analysis. Tools are currently programmed in Bash shell, Python or R languages, each with their own README files.  

- pytools: directory with tools developed with Python
- rTools: directory with tools (functions) developed for R
